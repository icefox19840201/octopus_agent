**要求：**

## 📤 发布到公众号

本技能支持将创作完成的文章直接发布到微信公众号草稿箱。

### 脚本调用方式

**脚本路径**: `skills/user_admin/wechat-article-writing/scripts/publish_to_wechat.py`

**调用命令**:

```bash
python publish_to_wechat.py --title "文章标题" --content "<html>文章内容</html>" --author "作者名" --digest "文章摘要" --cover "封面图路径"
```

**参数说明**:

- `--title` / `-t`: 文章标题（必填）
- `--content` / `-c`: 文章内容，支持HTML格式（必填）
- `--author` / `-a`: 作者名（可选）
- `--digest` / `-d`: 文章摘要，用于封面展示（可选）
- `--cover`: 封面图本地路径（可选，会自动使用正文第一张图片）
- `--file` / `-f`: 从文件读取文章内容（可选）

**使用示例**:

1. **直接发布**:
   
   ```bash
   python skills/user_admin/wechat-article-writing/scripts/publish_to_wechat.py \
   --title "晚清最诡异的一场灭门案" \
   --content "<h1>晚清最诡异的一场灭门案</h1><p>最开始，没有人意识到这件事的可怕……</p>" \
   --author "秘闻录" \
   --digest "一个被尘封百年的诡异案件"
   ```

2. **从文件发布**:
   
   ```bash
   python skills/user_admin/wechat-article-writing/scripts/publish_to_wechat.py \
   --title "90年代深圳流传的恐怖传闻" \
   --file article.html
   ```

**注意事项**:

- 文章内容需要使用HTML格式，支持常见的HTML标签（p, h1-h6, img, strong, em等）
- 图片需要先上传到微信服务器，脚本会自动处理本地图片路径
- 如果没有指定封面图，会自动使用正文中的第一张图片
- 发布成功后返回`media_id`，可在微信公众平台查看和群发

**发布流程**:

1. 完成文章内容创作和排版
2. 调用发布脚本，传入文章标题、内容等参数
3. 脚本自动获取access_token、上传图片、创建草稿
4. 发布成功后，登录微信公众平台 → 内容与互动 → 草稿箱查看
5. 在草稿箱中预览、编辑后，可选择立即群发或定时群发

## 🎬 创作流程

### 第一步：选题定位

选择具有以下特质的题材：

- 历史中的诡异事件
- 民间流传的禁忌传说
- 人性阴暗面的真实案例
- 未被官方记载的秘密
- 时代背景下的荒诞悲剧

### 第二步：构建氛围

1. **设定场景**：选择具有压抑感的时空背景
2. **引入视角**：用第一人称或亲历者视角讲述
3. **铺垫悬念**：在开头就埋下疑问

### 第三步：故事展开

1. **细节描写**：用感官细节营造真实感
2. **节奏控制**：张弛有度，层层递进
3. **情绪渲染**：让读者产生代入感

### 第四步：高潮与反转

1. **揭示真相**：但不要全部揭示
2. **人性反思**：怪谈背后的人性思考
3. **余味悠长**：让读者久久不能平静

### 第五步：视觉呈现

1. **配图生成**：根据内容生成氛围感图片，图片要求电影级，不允许卡通风格
2. **排版优化**：适配公众号阅读习惯
3. **发布推广**：一键发布到公众号草稿箱

---

### 第六步：引导互动，关注

文末引导读者留言，关注，评论，点赞，转发等增加互动，增加粉丝引爆流量

## ⚠️ 注意事项

1. **所有文案必须配图**，配图风格符合中式怪谈氛围
2. **生成好内容后，必须调用脚本将内容发布到公众号**，如果没有发布成功，需要明确说明原因
3. **保持神秘感**，不要把故事讲得太满
4. **尊重历史**，怪谈可以虚构，但背景要真实
5. **把握尺度**，恐怖但不低俗，猎奇但不恶心
6. **以上内容需要严格执行**
