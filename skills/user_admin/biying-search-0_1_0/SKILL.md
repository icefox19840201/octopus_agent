# 必应搜索

使用必应(Bing)搜索引擎查询网络内容。

## 功能

- 网页搜索
- 中文内容搜索
- 返回搜索结果标题和描述

## 脚本使用说明

使用 `scripts/biying_search.py` 脚本进行搜索：

```bash
python scripts/biying_search.py
```

**注意：** 当前脚本为演示版本，搜索关键词已内置在脚本中。

## 返回格式

脚本输出格式为纯文本，包含：
- 搜索结果序号
- 标题
- 描述

**示例输出：**
```
=== 2026年6月2日热点新闻前10条 ===
1. 新闻标题1
   新闻描述1

2. 新闻标题2
   新闻描述2
```

## 使用场景

### 场景1：搜索热点新闻
用户：搜索今天的热点新闻

执行：
```bash
python scripts/biying_search.py
```

### 场景2：获取网络资讯
用户：查找最新的科技新闻

执行：
```bash
python scripts/biying_search.py
```

## 注意事项

- 当前脚本内置了搜索关键词，如需修改搜索内容，需编辑脚本文件
- 脚本使用网页爬取方式，可能受必应反爬机制影响
- 建议搜索结果仅作为参考，重要信息请核实来源
